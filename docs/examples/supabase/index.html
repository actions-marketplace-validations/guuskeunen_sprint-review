Sprint review

November 9 to November 22, 2026

This sprint

Teams can watch Warehouse query health, latency and capacity in Observability.

  • Warehouse report
  • Unified logs
  • OAuth apps
  • Issues
  • Table Editor
  • Account security
This sprint's biggest visible change is the Warehouse report in Observability: query rate, outcomes, latency, capacity and worker activity, with date controls. Then Unified Logs saved views, the OAuth consent screen, and Issues replacing Advisors. Table Editor and account security round it out.

Warehouse report More insight

Warehouse query activity, latency and capacity now show in Observability.

  • Query rate, errors, timeouts and cancellations share one report
  • Query duration and worker wait times show in milliseconds
  • Separate sections cover used worker slots, rejected requests and started workers
  • Date range and refresh stay within how long your plan keeps logs
Open Observability, then Warehouse, on a project with Warehouse access. Scroll from query rate down through latency, Capacity and Worker activity, then change the date range. Finish on the integration overview, which now has a Workload section with last-hour query rate and p95 duration.

Unified logs Faster work

Saved views in Unified Logs now open from the filter sidebar.

  • Filter combinations save as views, opened from a sidebar panel
  • New projects start with Errors, Failed requests and Database health views
  • Attribute values filter in one click from the overview panel
  • On phones, the search bar and action icons no longer share a row
Click Saved views in the sidebar header: the filters swap for a views panel, with a breadcrumb back to Logs. Open a built-in view on a fresh project. Then click an attribute in the overview panel to filter. Shrink the window to show the two-row toolbar.

OAuth apps Better quality

People authorizing an OAuth app can now pick the organization and projects.

  • An organization selector on the consent screen; switching clears chosen projects
  • The project list loads as you scroll and search
  • Authorized apps lists for accounts and organizations show the grants currently active
  • OAuth apps that can be published have additional options
Use the example OAuth app with an account that has several organizations. Show the selector on the consent screen, switch organization and see the project selection reset. Then open the authorized apps lists, which now read real data instead of mocks.

Issues More insight

Advisor findings now appear as issues, with a list and a detail page.

  • Advisors is renamed Issues in the navigation
  • Issues carry the same findings the advisors already reported
  • A list of issues and a page for each one
  • Issues show on the project homepage
Start on the project homepage and show the issues there. Open the Issues list from the navigation, then click one to reach its detail page. Mention that the data is the same advisor lints as before, only presented differently.

Account security

Email, password and linked sign-ins appear as separate rows in Sign-in methods.

Table Editor: A context menu on each table lists its actions: Edit, duplicate and delete work on tables that are not open: The more options button appears on hover for every row: The command menu finds any table and shows resources related to it Account security: Accounts without a password get a Password row with Add: More providers show a Connect option by default: A backup authenticator is offered after saving recovery codes: Sign-out always reaches the sign-in page, even if data clearing fails
