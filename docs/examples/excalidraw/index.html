Sprint review

November 9 to November 22, 2026

This sprint

Text editing keeps focus across tabs, updates automatically and zooms precisely.

  • Text editing
  • Text formatting
  • Minimap
  • Canvas tools
This sprint focused on making text editing much smoother on the canvas. Switching tabs no longer closes your text draft, zoom stays anchored to your caret, and multi-line text stops jittering. We also introduced a minimap for navigating large boards easily.

Text editing Faster work

Switching tabs or apps keeps your open text draft active without closing.

  • The text editor submits only when clicking elsewhere in the document.
  • Remote updates sync into the open editor until typing begins.
  • Closing the drawing removes background text editor listeners.
Show typing text, switching to another browser tab, and switching back: the editor stays open. Show remote text updating live inside the open editor before you type.

Text formatting Better quality

Text resizes smoothly from its edges while staying anchored on zoom.

  • Drag text sides to wrap lines directly while editing.
  • Centered multi-line text stops jittering and shifting between keystrokes.
  • Keyboard zoom anchors on the active text cursor position.
Demonstrate dragging the side handle of a text element while actively typing. Show zooming with Cmd/Ctrl + plus/minus to highlight how the viewport anchors on the cursor.

Minimap Faster work

Navigate large drawings with an interactive mini map preview.

  • Toggle an interactive minimap to preview and drag around the canvas.
  • Apps embedding Excalidraw can hide the minimap toolbar control.
Show the new minimap button in the bottom left, toggle it open, and drag the viewport outline across a large scene. Mention that host applications can disable it via UI flags.

Canvas tools Less manual work

Flowchart arrow navigation and selection wrapping follow canvas layout.

  • Alt with arrow keys jumps directly to the nearest visible shape.
  • Pressing w wraps inner elements into a parent frame.
Demonstrate Alt+arrow keys navigating between nodes in a flowchart, highlighting how distance scoring picks nearby targets predictable. Then show wrapping an area in a frame using hotkey w.
