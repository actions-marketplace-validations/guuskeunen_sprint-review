# Security policy

## Reporting a vulnerability

Please don't open a public issue. Use GitHub's private reporting instead: **Security → Report a vulnerability** on [the repository](https://github.com/guuskeunen/sprint-review/security/advisories/new).

You'll get an answer within a few days. Fixes go out as a patch release, credited to you unless you'd rather not.

## Supported versions

The latest minor version gets security fixes.
